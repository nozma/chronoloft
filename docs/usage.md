# 使い方

[README](../README.md) / [開発ガイド](development.md) / [リリースガイド](releasing.md)

## アプリの起動と終了

Macの `Chronoloft.app` を起動して使用します。
赤い閉じるボタンでウィンドウを閉じてもアプリは常駐し、LANアクセスも継続します。
Dockのアイコンをクリックすると同じ画面を再表示します。
完全に終了する場合は、⌘Qまたはアプリメニューの「終了」を使ってください。
Macのスリープ中や、アプリを終了している間はLANアクセスを利用できません。

## 同じLANの別端末から利用する

1. 起動元PCの設定画面で「LANアクセス」を開く。
2. 「同じLAN内からのアクセスを許可」をオンにし、パスワード（8〜256文字）を設定する。
3. 「適用」を押し、表示されたURLを同じLANのスマートフォンや別PCのブラウザーで開く。
4. 設定したパスワードでログインする。

LANアクセスは初期状態では無効です。
端末名とLAN設定も、ほかの設定と同じ「適用」で保存します。「キャンセル」や保存せずに閉じた場合は変更を破棄します。

### 接続先と利用条件

通常のポート番号は5180です。再起動時は前のプロセスの終了を最大2秒待って再試行し、それでも使用中なら別の番号を選びます。
接続できない場合は、起動元PCの設定画面に表示されたURLを確認してください。OSのファイアウォールで許可が必要な場合があります。
起動元PCのlocalhostからは、パスワードなしで利用・設定できます。

LAN共有はHTTP接続で、通信は暗号化されません。信頼できる自宅LANで使用し、他サービスのパスワードは使い回さないでください。
ルーターのポート開放は不要です。
開発時の起動方法とポート番号は[開発ガイド](development.md#ブラウザーで開発する)を参照してください。

### ログインの有効期間

ログイン状態は端末ごとに保存され、アプリを再起動しても保持されます。
画面を開いたときやクリック・キー入力・スクロール時に期限を更新します。更新通信は最大1分に1回です。
バックグラウンドの定期通信では延長せず、最後の利用から7日間経過すると再ログインが必要です。
パスワードの変更やLANアクセスの無効化は、全端末のログインを無効にします。

## 端末別のストップウォッチ

1台の起動PCへLAN接続した各ブラウザーで、それぞれ独立した計測を開始できます。
設定画面の「LANアクセス」で「この端末の名前」を変更すると、操作対象を見分けやすくなります。
同じブラウザー・同じ接続先の複数タブは、同じ端末として扱います。

### ほかの端末の計測を操作する

「ほかの端末のストップウォッチ」には、接続先の起動PCで管理している他端末の計測が表示されます。
詳細・開始時刻の編集、終了・保存、キャンセルができます。
詳細・開始時刻は「編集」を開き、「変更を保存」で確定します。
状態は約3秒ごとに更新され、同時編集で古くなった操作はエラーになります。

各PCで個別起動したChronoloft同士の接続・DB統合には対応していません。

### Discordへの表示

Discord表示の対象は、起動PC自身のデスクトップ画面またはlocalhostから開始した計測だけです。
LAN接続側の計測は表示しません。LAN側から起動PCの計測を操作した場合は、その計測のDiscord表示を更新します。

### 計測と記録の保持

保存確認を取り消して計測へ戻ると、確認画面を開いていた時間も含めます。休憩時間を除外する一時停止機能はありません。
計測は起動PCのDBに保存するため、ブラウザーを閉じたり接続が切れたりしても保持されます。起動PCが停止中は取得・操作できません。

旧版のブラウザーに残っている計測は初回接続時に取り込みます。
取り込みに失敗した場合は警告を表示し、元データをブラウザーに残します。計測管理用の追加テーブルは起動時に作成します。

## アプリを更新する

Macのアプリメニューから「アップデートを確認…」を選び、案内に従って更新します。
更新時にはアプリが再起動します。

ストップウォッチの計測と保存を終えてから更新してください。
