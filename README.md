# Chronoloft

Discordへのステータス表示機能を備えた、個人利用向けのアクティビティ記録ツールです。

- アクティビティの記録とストップウォッチによる時間計測
- 計測中のアクティビティをDiscordに表示
- 同じLANのスマートフォンや別PCからの記録・計測操作

## 対応環境

macOS 26以降のApple Silicon搭載Macで利用できます。

## 使い方

起動・終了、LAN接続、ストップウォッチ、アプリの更新については[使い方](docs/usage.md)を参照してください。
